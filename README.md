# WORKAEM: вирусные реакции

Скилл для Claude Code: `.claude/skills/reaction-video/`. Он делает «безликую» реакцию на ролик:
- стоп-кадры с зумом и репликами;
- озвучка офлайн-голосами Piper;
- мультяшные реакторы, которые открывают рот в такт своему голосу;
- поп-субтитры, SFX, мастеринг громкости под YouTube;
- кликбейтное превью, варианты названий и описание.

Скилл умеет выучить подачу конкретного реактора по его ролику: ритм, частоту реакций, словечки и приёмы.

## Как пользоваться
1. Один раз: `bash .claude/skills/reaction-video/scripts/setup.sh`
2. Положи исходник в `reactions/<имя>/input/source.mp4`, а если нужен чужой стиль, его ролик в `style_ref/ref.mp4`.
3. Напиши Claude: «сделай реакцию <имя>».

Формат по умолчанию: 16:9, вертикальный ролик по центру, один реактор справа, английский. Шаблон проекта: `reactions/_template/`.
