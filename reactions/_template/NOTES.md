# Reaction project template

Default format: 16:9 YouTube, vertical (9:16) source centered slightly left, blurred sides,
one cartoon reactor (Max) on the right, English AI voice (Piper), pop captions under the video.

New reaction: copy this folder to `reactions/<slug>/`, put the clip in `input/source.mp4`,
then ask Claude "сделай реакцию <slug>".

Delivery style: `.claude/skills/reaction-video/reference/styles/` (yxl-salah.md once the
reference has been analysed; solo-streamer.md until then).
